# Batch-Assign-Animations - Unity

1. Assign multiple animations to legacy animation component for unity
2. Add the AnimationAssigner.cs file to your editor folder.
3. Refresh unity ediotr. 
4. Access the Batch Assign Animations from Tools menu.
5. In the Batch-Assign-Animations window..
6. Select Target Component field add game object that has Animation compnent 
7. In project window Select all .FBX or .Anim file you want to assign.
8. Click on button "Assign Selected Clips"

Common Fix for "Generic" vs "Legacy": If you are using the Animation component (Legacy system), ensure your Rig settings match:
1. Select FBX.
2. Go to Rig tab.
3. Change Animation Type to Legacy.
4. Hit Apply.
