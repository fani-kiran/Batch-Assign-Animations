# Batch-Assign-Animations - Unity
Assign multiple animations to legacy animation component for unity
Add the AnimationAssigner.cs file to your editor folder.
Refresh unity ediotr. 
Access the Batch Assign Animations from Tools menu.
In the Batch-Assign-Animations window..
Select Target Component field add game object that has Animation compnent 
In project window Select all .FBX or .Anim file you want to assign.
Click on button "Assign Selected Clips"
